# Hello! I'm Isaiah 👋

I'm a senior CS major at the University of Mary Washington (graduating May 2027), based in Fredericksburg, VA. I build games, mostly gameplay systems in Godot and C++, and I like the server side of games too. I've been running my own Minecraft server for a year and I'm now writing custom plugins for it.

## What I'm working on

- **Garden Sprouts** – An educational game for preschoolers (ages 3–5) about pollination and why insects matter to the food we eat. It's an independent study project built with Downtown Greens, a local non-profit. I'm handling most of the programming and design on a two-person team.
- **Cozy cooking game** – A Godot 4 game with seed growing, a pantry, inventory and hotbar systems, and a tag-based system that procedurally generates dishes from your ingredients.
- **Minecraft server plugins** – Custom Paper plugins in Java for a small server I've self-hosted on an old Debian laptop for about a year. I set up the port forwarding, auto-restarts, and backups myself.
